# Siger.js
## Javascript Game engine
This is a 3d game engine like library written in javascript
As of now it dont use any external library .

It uses WebGL renderer to render game.
## Example
``` javascript
// import the siger class
 import {Siger} from "Siger"
 //take instance of Siger class
 let sg=new Siger()
 //get and initiallize siger engine
const engine=new sg.SigerEngine()
engine.init()
````
